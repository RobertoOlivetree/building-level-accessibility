# Input data

This directory contains or documents the spatial input data required to reproduce the analytical workflow.

The term `raw` refers to the input datasets used by the notebooks in this repository. Some of these files are prepared analytical inputs derived from original third-party source datasets and should not be interpreted as untouched source data.

Large datasets and third-party data are not necessarily redistributed directly through GitHub. Where redistribution is restricted or impractical, the original source and acquisition information are documented below.
